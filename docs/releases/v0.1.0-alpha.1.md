# TOKEN v0.1.0-alpha.1

First public open-source alpha release for TOKEN.

## Included

- TOKEN vector identity: master logo, compact mark, and README hero.
- GitHub Actions CI on Python 3.12 and 3.13.
- Apache License 2.0.
- Public release metadata and documentation.
- Verified TOKEN V1 runtime.

## Runtime behavior

This release packaging does not change TOKEN runtime behavior. The public snapshot preserves the verified `src/token_runtime/` source byte-for-byte from the release candidate.

The package version is PEP 440 `0.1.0a1`, published as Git tag/release `v0.1.0-alpha.1`.

## Evidence boundary

The published benchmark and paired-live figures are bounded alpha evidence, not universal quality or currency-savings guarantees. See `docs/ALPHA-STATUS.md` for the public verification summary.
