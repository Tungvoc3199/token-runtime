# TOKEN v0.1.0-alpha.1

First public-ready alpha packaging release for TOKEN.

## Included

- Approved TOKEN vector identity: master logo, compact mark, and README hero.
- Real GitHub Actions CI on Python 3.12 and 3.13.
- Apache License 2.0.
- Public release metadata and README release surface.
- Existing verified TOKEN V1 runtime from `token-v1-core`.

## Runtime behavior

This release does **not** change TOKEN runtime behavior. No file under `src/token_runtime/` is modified by `TOKEN-PUBLIC-READY-1`.

The package version remains PEP 440 `0.1.0a1`, published as Git tag/release `v0.1.0-alpha.1`.

## Verified alpha evidence

- Live paired example: 6,975 → 3,927 input tokens (**43.70% reduction**) with identical paired output.
- Final 64-workload corpus: **28.53% eligible-workload estimated saving**, **10.61% overall estimated saving**.
- Protected-byte fidelity: **100%**.
- Recovery-reference resolution: **100%**.

These are bounded alpha results, not universal quality or billed-cost guarantees.
