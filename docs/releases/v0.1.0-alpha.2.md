# TOKEN v0.1.0-alpha.2

Second alpha release candidate for TOKEN, focused on compatibility evolution, deterministic distribution qualification, and fail-safe multi-provider growth without changing the safety-first optimizer contract.

## Included

- Stable evolution contracts, capability registry, compatibility matrix, feature-flag policy, and conformance scaffolding.
- Codex CLI 0.154.0 request/response boundary recertification with native/internal state kept passthrough-safe where TOKEN cannot observe semantics.
- Thin optional agent-integration framework that reuses TOKEN Core instead of forking optimization logic.
- Anthropic Messages and Gemini GenerateContent adapters with offline conformance, both still `PASSTHROUGH_ONLY` and not production gateway-wired.
- Compatibility certification governance with exact-version scope and fail-closed unknown capability behavior.
- Deterministic public-release and distribution qualification for wheel/sdist, pip, uv-tool, provenance, and upgrade/rollback.
- Anthropic preserved-thinking certification evidence: 5 BYPASS / 0 OPTIMIZE; replayed thinking remains passthrough-safe and `PASSTHROUGH_ONLY`.

## Release identity

The package version is PEP 440 `0.1.0a2`, mapped exactly to release label `v0.1.0-alpha.2`.

## Preserved-thinking evidence boundary

The preserved-thinking checkpoint used offline conformance evidence only. It required no live Anthropic API call and incurred no Anthropic evaluation cost. This release does not promote preserved thinking beyond `PASSTHROUGH_ONLY`.

## Compatibility boundary

Canonical source contains native Anthropic and Gemini adapters/conformance, but native Anthropic and Gemini routes remain not production gateway-wired. Unknown or uncertified client/provider/model/version combinations remain fail-safe and must not inherit certification by name similarity.

## Claims boundary

TOKEN does not claim universal zero quality regression, a universal token-reduction percentage, guaranteed currency savings, broad provider-cache non-regression, or production native Anthropic/Gemini routing. Performance claims remain limited to the bounded evidence in `docs/CLAIMS.md`.

## Distribution boundary

Alpha.2 artifacts are qualified through deterministic sanitized public candidates. Qualification verifies runtime-digest equivalence, exact artifact metadata, wheel/sdist reproducibility, installed package metadata, pip/uv-tool smoke tests, and `0.1.0a1 -> 0.1.0a2 -> 0.1.0a1` upgrade/rollback. PyPI publication remains a separate owner-gated action.

## Golden baseline

`TOKEN-V1-ALPHA-STABLE-20260909` remains immutable and separate from normal development.
