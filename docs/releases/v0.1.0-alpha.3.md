# TOKEN v0.1.0-alpha.3

Third alpha release candidate for TOKEN, focused on safer protocol evolution, OpenAI Agents API conformance boundaries, onboarding UX, and release qualification hardening.

## Included

- Protocol-selection isolation: provider/model changes do not silently select a different wire adapter; protocol changes remain explicit and conformance-gated.
- OpenAI Agents API offline conformance for durable/managed session semantics. Native session state remains protected and `PASSTHROUGH_ONLY`; this release does not enable production Agents API routing.
- First-run onboarding improvements: published-package Quickstart paths and actionable `token doctor` output when config is missing, without Python tracebacks.
- Distribution upgrade/rollback qualification now derives prior and candidate versions from wheel metadata instead of hard-coding Alpha.2.
- Alpha.3 qualification uses the exact published Alpha.2 wheel as the rollback anchor and verifies its frozen SHA256 before install transitions.
- Controlled build tooling moves from yanked `wheel==0.46.1` to non-yanked `wheel==0.46.3`.

## Release identity

The package version is PEP 440 `0.1.0a3`, mapped exactly to release label `v0.1.0-alpha.3`.

## Compatibility boundary

OpenAI Agents API support in this release is conformance-only. Durable session state, native compaction/recovery state, and unknown managed events remain opaque/protected and must not be rewritten by TOKEN.

## Claims boundary

TOKEN still does not claim universal zero quality regression, a universal token-reduction percentage, guaranteed currency savings, broad provider-cache non-regression, or production native Anthropic/Gemini/Agents API routing. Existing bounded benchmark claims remain unchanged.

## Distribution boundary

Alpha.3 qualification verifies deterministic sanitized candidates, runtime-digest equivalence, exact wheel/sdist metadata, byte reproducibility, pip/uv-tool install smoke tests, and exact published `0.1.0a2 -> 0.1.0a3 -> 0.1.0a2` upgrade/rollback. GitHub release creation and PyPI publication remain separate owner-gated actions.

## Golden baseline

`TOKEN-V1-ALPHA-STABLE-20260909` remains immutable and separate from normal development.
